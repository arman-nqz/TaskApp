# Architecture Decision Records (ADR)

Architecture Decision Records (ADRs) capture important architectural choices made during the lifecycle of the Task Management Application, including the context that led to the decision, the chosen direction, and the consequences.

We follow the standard [Michael Nygard format](https://cognitect.com/blog/2011/11/15/documenting-architecture-decisions) for ADRs.
